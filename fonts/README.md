# Fontes

## PressStart2P-Regular

**Download:** https://fonts.google.com/specimen/Press+Start+2P → botão "Download family" (canto superior direito).

Extrai o ZIP e salva o arquivo `PressStart2P-Regular.ttf` **nesta pasta** (`res://fonts/PressStart2P-Regular.ttf`).

O jogo detecta automaticamente. Sem o arquivo, ele usa a fonte padrão do Godot.
